# Field-Kit Build Guide (weekend project)

1. Build or reuse TPBR piezo stack at 54.74°
2. Print alignment mount (jig/ folder)
3. Wire to ESP32 (schematic in hardware/)
4. Flash software/arduino_firmware.ino
5. Run python kalman_sim.py for live plotting
6. Take it outside — walk 100 m and see how far the dead-reckoning stays accurate

Field tips: Use a small vacuum chamber (syringe) for Q > 500k. Data in DATA.md.
